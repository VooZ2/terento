Installa mappe gratuite sul tuo Garmin Edge da Mac

I ciclocomputer Garmin Edge più recenti non compaiono sul Mac come disco, quindi non puoi semplicemente copiarci un file di mappa. Terento installa mappe OpenStreetMap gratuite, o un tuo file di mappa compatibile, sui ciclocomputer Garmin Edge con supporto alle mappe, come Edge 540, 840 e 1050.

Scarica

Cosa ti serve

  • Mac Apple Silicon con macOS 13 o versioni successive
  • Garmin Edge recente con supporto alle mappe
  • Cavo USB che supporti il trasferimento dati

Dopo il collegamento, Terento controlla l’Edge e ti dice se può installare le mappe. La pagina Compatibilità elenca i modelli con installazioni riuscite; un modello assente non è per forza non supportato.

Installa una mappa sul tuo Edge

  1. 1

    Scarica e apri Terento

    Scarica Terento, trascinalo dall’immagine disco in Applicazioni e aprilo da lì. Alla prima apertura macOS chiede se aprire un’app scaricata da Internet: scegli Apri.

  2. 2

    Collega l’Edge

    Chiudi Garmin Express, se è aperto. Collega l’Edge direttamente al Mac con un cavo USB dati, non tramite un hub. Se macOS chiede se consentire il collegamento dell’accessorio, scegli Consenti. Terento trova l’Edge entro 2 minuti e controlla se può installare le mappe.

  3. 3

    Scegli una mappa

    Scegli un provider e una regione dal catalogo, oppure aggiungi dal Mac un tuo file di mappa .img compatibile. Confronta gli stili di mappa per vedere come ogni mappa mostra strade e sentieri.

  4. 4

    Installa

    Avvia l’installazione e lascia l’Edge collegato finché Terento non indica che l’installazione è completa. Poi scollega l’Edge.

Mostra la mappa sul tuo Edge

Scollega l’Edge, apri le impostazioni delle mappe e verifica che la nuova mappa sia attiva. Se non è nell’elenco, riavvia l’Edge. Se più mappe coprono la stessa zona, disattiva quelle che non vuoi vedere.

Se qualcosa non funziona

Il Garmin Edge non compare in Terento

Usa un cavo USB dati, collega l’Edge direttamente invece che tramite un hub, chiudi Garmin Express e le app di trasferimento file e attendi fino a 2 minuti. Altro aiuto: Orologio Garmin non rilevato dal Mac, Garmin Express o un’altra app sta usando l’orologio.

L’installazione o l’aggiornamento non è disponibile

Le mappe temporaneamente non disponibili restano visibili. Leggi il motivo indicato accanto alla mappa. Se il provider non è raggiungibile o i download sono sospesi, riprova più tardi. Se Terento non riesce a verificare la disponibilità attuale, controlla la connessione Internet e riprova. Le mappe già installate restano disponibili. Altro aiuto: L’elenco delle mappe Garmin non si carica o Terento va aggiornato, Download della mappa Garmin non riuscito.

Installazione non riuscita

Nella schermata di installazione non riuscita, scegli “Report issue”. Terento apre GitHub con il rapporto già compilato. Controllalo prima di pubblicarlo: le issue su GitHub sono pubbliche. Per assistenza via e-mail, indica il modello dell’Edge, la regione della mappa e cosa è successo. Altro aiuto: Installazione della mappa non riuscita: mappa rimasta sull’orologio, Come segnalare un problema con Terento.

Vedi tutte le soluzioni

Perché il tuo Garmin Edge non compare sul Mac

I modelli Edge più recenti, come Edge 540, 840 e 1050, scambiano file via USB come i telefoni Android. macOS non supporta questo collegamento in modo nativo, quindi l’Edge non compare nel Finder come disco e le guide che dicono di copiare un file di mappa nella cartella Garmin non funzionano con questi modelli. Terento comunica direttamente con l’Edge, quindi non ti servono Android File Transfer o OpenMTP.

Modelli Edge meno recenti

I modelli meno recenti, come Edge 1030 Plus e precedenti, di solito compaiono sul Mac come disco USB. Su questi puoi copiare tu stesso un file di mappa .img compatibile nella cartella Garmin del disco, senza Terento. Terento non è pensato per questi modelli.
