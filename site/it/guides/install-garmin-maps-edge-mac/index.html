Guida Garmin Edge

Installa mappe sul tuo Garmin Edge da Mac

I ciclocomputer Garmin Edge più recenti non compaiono sul Mac come disco, quindi non puoi semplicemente copiarci un file di mappa. Terento installa in tre passaggi mappe OpenStreetMap gratuite, o un tuo file di mappa compatibile, su un Edge con supporto alle mappe.

Perché è diverso

Perché il tuo Garmin Edge non compare sul Mac

I modelli Edge più recenti, come Edge 540, 840 e 1050, scambiano file via USB come i telefoni Android, usando MTP (Media Transfer Protocol). macOS non lo supporta in modo nativo, quindi l’Edge non compare nel Finder come disco e le guide che dicono di copiare un file di mappa nella cartella Garmin non funzionano con questi modelli. Terento comunica direttamente con l’Edge, quindi non ti servono Android File Transfer o OpenMTP.

Un controllo rapido

Prima di iniziare

  • Mac Apple Silicon con macOS 13 o versioni successive
  • Garmin Edge recente con supporto alle mappe
  • Cavo USB che supporti il trasferimento dati

Terento è pensato per i modelli Edge più recenti con supporto alle mappe che si collegano in questo modo: Edge 540, Edge 540 Solar, Edge 840, Edge 840 Solar, Edge 1040, Edge 1040 Solar, Edge 1050, Edge 550, Edge 850, Edge 1060, Edge MTB, Edge Explore 2, Edge Explore 3 ed Edge Explore 3 Plus. Dopo il collegamento, Terento controlla l’Edge e ti dice se può installare mappe. La pagina Compatibilità elenca i modelli esatti con installazioni riuscite; un modello assente non è necessariamente non supportato.

Niente Mac con Apple Silicon? L’installer web installa le mappe del catalogo da Chrome e da altri browser Chromium con WebUSB.

Tre passaggi

Installa una mappa sul tuo Edge

  1. 01

    Collega l’Edge

    Scarica Terento e aprilo. Chiudi Garmin Express, collega l’Edge direttamente al Mac con un cavo USB dati e attendi fino a 2 minuti che Terento lo rilevi.

  2. 02

    Scegli una mappa

    Scegli un provider e una regione dal catalogo, oppure aggiungi dal Mac un tuo file di mappa .img compatibile. Confronta gli stili di mappa per vedere come ogni mappa mostra strade e sentieri.

  3. 03

    Installa

    Avvia l’installazione e lascia l’Edge collegato finché Terento non indica che l’installazione è completa. Poi scollega l’Edge.

Dopo l’installazione

Mostra la mappa sul tuo Edge

Attiva la mappa

Scollega l’Edge, apri le impostazioni delle mappe e verifica che la nuova mappa sia attiva. Se non è nell’elenco, riavvia l’Edge. Se più mappe coprono la stessa zona, disattiva quelle che non vuoi vedere.

Il Garmin Edge non compare in Terento

Usa un cavo USB dati, collega l’Edge direttamente invece che tramite un hub, chiudi Garmin Express e le app di trasferimento file e attendi fino a 2 minuti. La guida alla risoluzione dei problemi ha altri passaggi; la maggior parte vale allo stesso modo per un orologio e per un Edge.

Modelli Edge meno recenti

I modelli meno recenti, come Edge 1030 Plus e precedenti, di solito compaiono sul Mac come disco USB. Su questi puoi copiare tu stesso un file di mappa .img compatibile nella cartella Garmin del disco, senza Terento. Terento non è pensato per questi modelli.
