Guida all’installazione su Mac

Installa mappe di terze parti sul tuo Garmin in tre semplici passaggi

Collega l’orologio, scegli una mappa e lascia che Terento gestisca l’installazione — senza trasferimenti manuali di file.

macOS 13+Apple SiliconSmartwatch Garmin con supporto alle mappe

Un controllo rapido

Prima di iniziare

  • Mac Apple Silicon
  • macOS 13 o successivo
  • Smartwatch Garmin con supporto alle mappe
  • Cavo USB per il trasferimento dati

Terento controlla l’orologio dopo il collegamento. Consulta le prove attuali di compatibilità per i modelli e le varianti testati durante installazioni reali.

Vedi le prove attuali di compatibilità →

Il percorso

Installa in tre passaggi

  1. 01

    Collega

    Collega lo smartwatch con un cavo USB dati. Terento lo riconosce e controlla se puoi continuare in sicurezza.

  2. 02

    Installa

    Scegli una mappa dal catalogo oppure aggiungi il tuo file .img compatibile. Terento gestisce l’installazione.

    1. Scegli dal catalogo

      Scegli una regione dal catalogo Freizeitkarte o OpenTopoMap.

    2. Aggiungi la tua mappa

      Aggiungi una mappa .img compatibile dal Mac.

  3. 03

    Fatto

    Quando Terento conferma che l’installazione è completa, scollega l’orologio in sicurezza e verifica che la mappa sia disponibile.

Serve aiuto?

Se qualcosa non funziona

Terento non rileva l’orologio

Attendi 1–2 minuti dopo il collegamento. Se lo smartwatch non appare, ricollegalo, controlla il cavo dati e chiudi le altre app che potrebbero usarlo.

Installazione non riuscita

Se un’installazione non riesce, Terento proporrà di aprire una issue su GitHub con le informazioni diagnostiche necessarie per analizzare il problema.

La mappa è installata ma non è visibile

Ricollega o riavvia l’orologio e controlla le impostazioni della mappa. Se la mappa non appare ancora, apri una issue oppure invia il log diagnostico a hello@terento.app.
