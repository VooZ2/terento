# Installer des cartes sur votre Garmin Edge depuis un Mac

Les compteurs vélo Garmin Edge récents n’apparaissent pas comme un disque sur un Mac : impossible d’y copier simplement un fichier de carte. Terento installe en trois étapes des cartes OpenStreetMap gratuites, ou votre propre fichier de carte compatible, sur un Edge qui prend en charge les cartes.

Pourquoi c’est différent

## Pourquoi votre Garmin Edge n’apparaît pas sur votre Mac

Les Edge récents, comme les Edge 540, 840 et 1050, échangent des fichiers en USB comme les téléphones Android, avec le MTP (Media Transfer Protocol). macOS ne le prend pas en charge nativement : l’Edge n’apparaît donc pas comme un disque dans le Finder, et les guides qui conseillent de copier un fichier de carte dans le dossier Garmin ne fonctionnent pas pour ces modèles. Terento dialogue directement avec l’Edge : vous n’avez besoin ni d’Android File Transfer ni d’OpenMTP.

Vérification rapide

## Avant de commencer

- Mac Apple Silicon avec macOS 13 ou version ultérieure
- Garmin Edge récent prenant en charge les cartes
- Câble USB permettant le transfert de données

Terento est conçu pour les Edge récents prenant en charge les cartes qui se connectent de cette façon : Edge 540, Edge 540 Solar, Edge 840, Edge 840 Solar, Edge 1040, Edge 1040 Solar, Edge 1050, Edge 550, Edge 850, Edge 1060, Edge MTB, Edge Explore 2, Edge Explore 3 et Edge Explore 3 Plus. Après la connexion, Terento vérifie l’Edge et vous indique s’il peut installer des cartes. La page Compatibilité liste les modèles exacts avec des installations réussies ; l’absence d’un modèle ne signifie pas forcément qu’il n’est pas pris en charge.

[Voir les preuves de compatibilité actuelles](https://terento.app/fr/compatibility/)

Pas de Mac Apple Silicon ? L’ [installateur web](https://terento.app/fr/install/) installe les cartes du catalogue depuis Chrome et d’autres navigateurs Chromium compatibles WebUSB.

Trois étapes

## Installer une carte sur votre Edge

1. Connecter l’Edge

[Téléchargez Terento](https://terento.app/fr/download/) et ouvrez-le. Quittez Garmin Express, connectez l’Edge directement au Mac avec un câble USB de données et attendez jusqu’à 2 minutes que Terento le détecte.

2. Choisir une carte

Choisissez un fournisseur et une région dans le catalogue, ou ajoutez depuis votre Mac votre propre fichier de carte .img compatible. [Comparez les styles de carte](https://terento.app/fr/map-styles/) pour voir comment chaque carte affiche routes et sentiers.

3. Installer

Lancez l’installation et gardez l’Edge connecté jusqu’à ce que Terento indique que l’installation est terminée. Déconnectez ensuite l’Edge.

Après l’installation

## Afficher la carte sur votre Edge

### Activer la carte

Déconnectez l’Edge, ouvrez ses réglages de carte et vérifiez que la nouvelle carte est activée. Si elle n’est pas listée, redémarrez l’Edge. Si plusieurs cartes couvrent la même zone, désactivez celles que vous ne voulez pas voir.

### Le Garmin Edge n’apparaît pas dans Terento

Utilisez un câble USB de données, connectez l’Edge directement plutôt que via un hub, quittez Garmin Express et les apps de transfert de fichiers, puis attendez jusqu’à 2 minutes. Le [guide de dépannage](https://terento.app/fr/guides/troubleshooting/) propose d’autres étapes ; la plupart s’appliquent de la même façon à une montre et à un Edge.

### Anciens modèles Edge

Les modèles plus anciens, comme l’Edge 1030 Plus et les précédents, apparaissent généralement sur un Mac comme un disque USB. Sur ceux-ci, vous pouvez copier vous-même un fichier de carte .img compatible dans le dossier Garmin du disque, sans Terento. Terento n’est pas conçu pour ces modèles.
