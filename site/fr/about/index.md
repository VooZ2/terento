# Une appli de cartes gratuite, faite par un randonneur Garmin

Terento installe des cartes communautaires gratuites sur les montres Garmin et les compteurs vélo Edge. C’est une application Mac gratuite et open source, avec un installateur web qui fonctionne dans votre navigateur.

[Télécharger](https://terento.app/fr/download/)

## Pourquoi je l’ai créé

Je suis Gediminas. J’utilise une Garmin et j’adore randonner en montagne. Avant un voyage, je veux que ma montre ait les cartes de ma destination, et les y mettre demandait plus d’efforts que nécessaire.

J’ai créé Terento pour simplifier cela, pour moi et pour tous ceux qui ont une Garmin. Il est gratuit et open source parce que je veux qu’il soit utile à la communauté.

## Ce qu’est Terento, et ce qu’il n’est pas

### Ce qu’il est

- Une application Mac gratuite pour les Mac Apple Silicon sous macOS 13 ou version ultérieure.

- Un [installateur web](https://terento.app/fr/install/) pour Chrome, Microsoft Edge, Opera ou Brave sur Mac ; Linux est encore en test.

- Un moyen d’installer, de mettre à jour et de supprimer des cartes gratuites sur les montres Garmin et les compteurs vélo Edge récents compatibles avec les cartes.

- Une place aussi pour votre propre carte compatible (.img). Vos cartes personnelles ne se mettent pas à jour automatiquement.

- Gratuit, sans compte.

### Ce qu’il n’est pas

- **Un produit Garmin.** Garmin ne fabrique, ne recommande ni ne certifie Terento.

- **Un éditeur de cartes.** Les cartes viennent des projets communautaires cités plus bas.

- **Une application de navigation.** Vous naviguez sur votre Garmin, comme d’habitude.

- **Une application pour Windows, téléphones ou tablettes.**

- **Un risque pour vos cartes Garmin d’origine.** Terento n’y touche jamais.

- **Une promesse que chaque Garmin fonctionne.** La page [Compatibilité](https://terento.app/fr/compatibility/) liste les modèles sur lesquels des cartes ont déjà été installées.

## Code ouvert, cartes communautaires

Le code de Terento est public sur [GitHub](https://github.com/VooZ2/terento), sous licence GPL-3.0. Vous pouvez le lire, signaler un problème ou aider à l’améliorer.

Les cartes sont réalisées par [OpenTopoMap](https://garmin.opentopomap.org/), [Freizeitkarte](https://www.freizeitkarte-osm.de/), [MapRando](https://ravenfeld.gitlab.io/open-garmin-map/), [BBBike](https://garmin.bbbike.org) et [OSMapaPL](https://osmapa-garmin.las.org.pl/), à partir des données des [contributeurs d’OpenStreetMap](https://www.openstreetmap.org/copyright). Terento récupère chaque carte auprès de son projet d’origine ; licences et attributions restent les leurs.
