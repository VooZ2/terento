Garmin Edge guide

# Install maps on your Garmin Edge from a Mac

Newer Garmin Edge bike computers don’t show up on a Mac as a drive, so you can’t simply copy a map file to them. Terento installs free OpenStreetMap maps, or your own compatible map file, on an Edge with map support in three steps.

Why it’s different

## Why your Garmin Edge doesn’t show up on your Mac

Newer Edge models, such as the Edge 540, 840 and 1050, share files over USB the way Android phones do, using MTP (Media Transfer Protocol). macOS has no built-in support for it, so the Edge doesn’t appear in Finder as a drive, and guides that tell you to copy a map file into the Garmin folder don’t work for these models. Terento talks to the Edge directly, so you don’t need Android File Transfer or OpenMTP.

A quick check

## Before you start

- Apple Silicon Mac with macOS 13 or later
- Newer Garmin Edge with map support
- USB cable that supports data transfer

Terento is designed for newer Edge models with map support that connect this way: Edge 540, Edge 540 Solar, Edge 840, Edge 840 Solar, Edge 1040, Edge 1040 Solar, Edge 1050, Edge 550, Edge 850, Edge 1060, Edge MTB, Edge Explore 2, Edge Explore 3 and Edge Explore 3 Plus. After you connect, Terento checks the Edge and tells you whether it can install maps. The Compatibility page lists the exact models with successful installations; a model missing from it is not necessarily unsupported.

[See current compatibility evidence](https://terento.app/compatibility/)

No Apple Silicon Mac? The [web installer](https://terento.app/install/) installs catalog maps from Chrome and other Chromium browsers with WebUSB.

Three steps

## Install a map on your Edge

1. Connect the Edge

[Download Terento](https://terento.app/download/) and open it. Quit Garmin Express, connect the Edge directly to your Mac with a USB data cable and wait up to 2 minutes while Terento finds it.

2. Choose a map

Choose a provider and a region from the catalog, or add your own compatible .img map file from your Mac. [Compare map styles](https://terento.app/map-styles/) to see how each map draws roads and trails.

3. Install

Start the installation and keep the Edge connected until Terento says the installation is complete. Then disconnect the Edge.

After installing

## Show the map on your Edge

### Turn the map on

Disconnect the Edge, open its map settings and make sure the new map is enabled. If it isn’t listed, restart the Edge. If several maps cover the same area, turn off the ones you don’t want to see.

### Garmin Edge not showing up in Terento

Use a USB data cable, connect the Edge directly instead of through a hub, quit Garmin Express and file-transfer apps, and wait up to 2 minutes. The [troubleshooting guide](https://terento.app/guides/troubleshooting/) has more steps; most of them work the same for a watch and an Edge.

### Older Edge models

Older models, such as the Edge 1030 Plus and earlier, usually show up on a Mac as a USB drive. On those, you can copy a compatible .img map file into the Garmin folder on the drive yourself, without Terento. Terento is not designed for these models.
