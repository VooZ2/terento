# Install free maps on your Garmin watch

Terento is a free, open-source way to install, update and manage third-party maps on Garmin watches: with a native Mac app or in your desktop browser.

[Download for Mac](https://terento.app/download/)
[Check compatibility](https://terento.app/compatibility/) [Install from your browser](https://terento.app/install/)

Terento showing third-party map installation progress on macOS

How it works

## Connect Install Done

Installing third-party maps should be simple and fast — no copying files by hand, no technical know-how.

Terento brings the whole process together in three simple steps.

1. Connect

Terento recognizes your Garmin and shows when it is ready.

2. Install

Choose maps from the catalog, or add your own compatible .img map.

3. Done

Your maps are installed and ready to use on your watch.

## Install maps

Choose maps from the catalog by region, or add your own compatible .img map.

## Manage maps

See what's installed, update maps when newer releases are available, and remove third-party maps managed by Terento. Original Garmin maps remain protected.

Web installer

## No app? Install from your browser.

Connect your Garmin with a USB cable, choose maps and install them straight from Chrome, Edge, Opera or Brave. Update or remove them later the same way.

Works on a Mac and, still in testing, on Linux. Not on Windows, phones or tablets yet.

## FAQ

Which Garmin watches work with Terento?

See the [Compatibility page](https://terento.app/compatibility/) for exact Garmin models and variants with at least one successful shared installation. A missing model is not necessarily unsupported.

Can I install third-party maps on a Garmin watch from a Mac without Garmin Express or BaseCamp?

Yes. Terento is designed to make third-party map management on macOS simple and fast — from choosing a map to installing, updating, and managing it on your Garmin watch. [Read the installation guide.](https://terento.app/guides/install-garmin-maps-mac/)

Can I add my own .img map?

Yes. Add a compatible .img map from your Mac and install it on your connected Garmin watch.

Can I update maps later?

Yes. Terento shows when newer releases are available and helps you update Terento-managed third-party maps.

Why isn’t my Garmin watch showing up on my Mac?

Connect the watch directly with a USB cable that supports data, unlock it and wait up to 2 minutes. If it still doesn’t appear, quit Garmin Express, Android File Transfer, OpenMTP and other apps that can use the watch.

What should I do if installation fails?

On the failed installation screen, choose “Report issue”. Terento opens GitHub with the report already filled in. Review it before posting: GitHub issues are public. For help by email, include your watch model, map region and what happened. [Read the troubleshooting guide.](https://terento.app/guides/troubleshooting/)

[Open an issue](https://github.com/VooZ2/terento/issues/new/choose) [Email support](mailto:hello@terento.app?subject=Terento%20installation%20issue)

Can I install maps without installing the app?

Yes. The [web installer](https://terento.app/install/) installs, updates and removes catalog maps from Chrome, Edge, Opera or Brave on a Mac, and on Linux, where it is still being tested. It does not work on Windows, phones or tablets yet, and it cannot add your own .img maps.
