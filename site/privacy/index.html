Privacy

This notice covers the public website terento.app and the Terento macOS beta. It is separate from the legal notices.

It does not cover the privacy practices of Freizeitkarte, OpenTopoMap, or OpenStreetMap. Map files are provided by their respective providers and are not personal data collected by Terento.

Data controller: Private individual. Contact: privacy@terento.app.

Website, app and data

What Terento processes.

Local app data

The website and app do not provide an account or login and do not require an email address. Device state, maps, Terento manifests and local installation records stay on your Mac. The app sends only the privacy-minimised diagnostic fields described below, by default, and never sends those local records.

Automatic update checks

The app may contact terento.app when it starts to check whether a newer version is available. This automatic request is not used for analytics or user tracking; it only fetches release metadata. Terento does not download, mount or install the DMG in the background.

Privacy-minimised compatibility diagnostics

The macOS beta sends privacy-minimised compatibility diagnostics by default to api.terento.app to improve installation reliability and compatibility coverage by watch model and firmware. There is no sharing choice in the installation flow. You can turn this stream off at any time under Terento → Diagnostics; doing so does not limit the app or map installation.

A report may contain random event and per-installation operation IDs, timestamp, watch model and family, sanitized raw MTP model label, firmware version, USB vendor and product identifiers, MTP transport, a category stating only whether local identity came from an MTP serial, Garmin Unit ID, or was unavailable, map provider, selected regions and releases, exact Terento release/build, macOS version, per-map outcome, failure stage, allowlisted Terento/native failure codes, whether device writing or cleanup started, and a coarse transfer-progress range. Pre-write provider and validation failures are kept separate from watch compatibility rates. It does not contain the Garmin Unit ID or serial value, local watch identifier, account information, email address, local file paths, MTP object IDs, Terento manifests, map files, map hashes, raw error text or diagnostic logs.

These diagnostics are used to improve Terento’s app quality, installation reliability and supported-device coverage. You can stop future sharing in Terento → Diagnostics. The app does not provide a delete action for uploaded diagnostics; contact privacy@terento.app for privacy-rights requests.

Privacy-minimised map-usage diagnostics

The app sends a separate stream of privacy-minimised map-usage diagnostics by default to measure map download and installation outcomes. Each event may contain only random event and operation IDs, timestamp, provider, map, region, event type, outcome and app build. It does not contain a watch model or identifier, serial or Garmin Unit ID value, account, local file path, manifest, map file or diagnostic log. You can turn this stream off under Terento → Diagnostics; doing so does not limit installation. Custom IMG installations are reported only through compatibility diagnostics and never through this map-usage stream.

Storage and public statistics

Compatibility reports and privacy-minimised map-statistics events are stored in Terento’s PostgreSQL database on its hosting infrastructure for no longer than 24 months and are then deleted. Access is restricted to the private administration service.

Terento publishes only reviewed aggregate compatibility statistics for models enabled for public display. Raw reports, map events, event IDs, firmware lists, error details and request metadata are not published.

Cloudflare and hosting

Cloudflare provides services used to deliver and secure the website and API, including DNS, HTTPS/TLS, content delivery, and protection against abusive traffic. The website, API and database run on Hostinger infrastructure. Terento and these providers may process IP addresses, request metadata and security-related information to operate and protect these services. Cloudflare’s privacy policy and Hostinger’s privacy policy apply. Data may be processed outside Lithuania or the EU under the providers’ service configurations and safeguards.

Umami analytics

The site loads the Umami analytics script from stats.enduristas.lt for all visitors to measure visits and download events. Umami does not use tracking cookies or create personal profiles. Visit statistics are processed on the basis of Terento’s legitimate interests under Article 6(1)(f) GDPR: understanding site reach and campaign performance, improving the public site, and supporting a free open-source project.

It may record the page path, referrer, browser, operating system, device type, and country-level context to produce aggregated statistics. When a campaign link includes UTM parameters, download events may include those non-personal campaign values to distinguish campaign sources and creative variants. This is campaign measurement, not personal profiling or targeted advertising. See the Umami FAQ.

Language preference

When you choose a site language, the site stores the preference as terento-language in your browser’s local storage. This is a user-requested preference, not advertising tracking.

Cookies — what applies

This site does not use advertising or profiling cookies. Umami visit statistics do not use tracking cookies and are enabled for all visitors. The language preference is stored in localStorage only when you choose a language. Cloudflare security cookies, if used, serve infrastructure and security purposes, not marketing.

There is no analytics consent popup or analytics settings control. You may object to this processing by contacting privacy@terento.app.

Your rights

Under the GDPR you may have rights to access, rectify, erase, restrict processing, object, data portability, withdraw consent and lodge a complaint with a supervisory authority. In Lithuania that is the State Data Protection Inspectorate (VDAI).

Use Terento → Diagnostics to stop future diagnostic sharing. The app does not provide a delete action for uploaded diagnostics. For privacy-rights requests, contact the data controller at privacy@terento.app. Nothing here limits those rights.

The controller relies on legitimate interests under Article 6(1)(f) GDPR to deliver and secure the website and API, prevent abuse, maintain network and information security, understand site reach, measure campaigns and improve Terento through privacy-minimised diagnostics not linked to an account or direct device identifier.

Datenschutz

Dieser Hinweis gilt für die öffentliche Website terento.app und die Terento-Beta für macOS. Er steht getrennt von den rechtlichen Hinweisen.

Er gilt nicht für die Datenschutzpraktiken von Freizeitkarte, OpenTopoMap oder OpenStreetMap. Kartendateien werden von den jeweiligen Anbietern bereitgestellt und sind keine von Terento erhobenen personenbezogenen Daten.

Verantwortlicher: Privatperson. Kontakt: privacy@terento.app.

Website, App und Daten

Was Terento verarbeitet.

Lokale App-Daten

Website und App bieten kein Konto und keinen Login und verlangen keine E-Mail-Adresse. Gerätezustand, Karten, Terento-Manifeste und lokale Installationsaufzeichnungen bleiben auf deinem Mac. Die App sendet standardmäßig nur die unten beschriebenen datensparsamen Diagnosefelder und niemals diese lokalen Aufzeichnungen.

Automatische Update-Prüfungen

Die App kann beim Start terento.app kontaktieren, um zu prüfen, ob eine neuere Version verfügbar ist. Diese automatische Anfrage wird nicht für Analysen oder Nutzerverfolgung verwendet, sondern ruft nur Release-Metadaten ab. Terento lädt die DMG nicht im Hintergrund herunter, bindet sie nicht ein und installiert sie nicht.

Datensparsame Kompatibilitätsdiagnose

Die macOS-Beta sendet standardmäßig datensparsame Kompatibilitätsdiagnosen an api.terento.app, um Installationszuverlässigkeit und Kompatibilitätsabdeckung nach Uhrenmodell und Firmware zu verbessern. Im Installationsablauf gibt es keine Freigabeauswahl. Du kannst diesen Datenstrom jederzeit unter Terento → Diagnostics deaktivieren; dadurch werden App oder Karteninstallation nicht eingeschränkt.

Ein Bericht kann zufällige Ereignis- und Installationsvorgangs-IDs, Zeitstempel, Uhrenmodell und -familie, eine bereinigte rohe MTP-Modellbezeichnung, Firmware-Version, USB-Hersteller- und Produktkennungen, MTP-Transport sowie eine Kategorie enthalten, die nur angibt, ob die lokale Identität aus einer MTP-Seriennummer, einer Garmin Unit ID oder aus keiner verfügbaren Quelle stammt. Hinzu kommen Kartenanbieter, ausgewählte Regionen und Ausgaben, die genaue Terento-Version samt Build, macOS-Version, das Ergebnis je Karte, Fehlerphase, freigegebene Terento- und native Fehlercodes, der Beginn von Schreiben oder Bereinigung sowie ein grober Übertragungsfortschritt. Fehler vor dem Schreiben werden von der Kompatibilitätsquote der Uhr getrennt. Der Wert der Garmin Unit ID oder Seriennummer, lokale Uhrenkennungen, Kontodaten, E-Mail-Adressen, lokale Dateipfade, MTP-Objekt-IDs, Terento-Manifeste, Kartendateien oder -Hashes, unbereinigte Fehlertexte und Diagnoseprotokolle sind nicht enthalten.

Diese Diagnosen dienen der Verbesserung von Terento, der Installationszuverlässigkeit und der Unterstützung weiterer Geräte. Du kannst die zukünftige Freigabe unter Terento → Diagnostics beenden. Die App bietet keine Löschfunktion für hochgeladene Diagnosen; für Datenschutzanfragen kontaktiere privacy@terento.app.

Datensparsame Karten-Nutzungsdiagnose

Die App sendet standardmäßig einen separaten Strom datensparsamer Karten-Nutzungsdiagnosen, um Ergebnisse von Kartendownloads und -installationen zu messen. Ein Ereignis enthält nur zufällige Ereignis- und Vorgangs-IDs, Zeitstempel, Anbieter, Karte, Region, Ereignistyp, Ergebnis und App-Build. Es enthält keine Uhrenkennung, Seriennummer oder Garmin Unit ID, Kontodaten, lokale Dateipfade, Manifeste, Kartendateien oder Diagnoseprotokolle. Du kannst diesen Datenstrom unter Terento → Diagnostics deaktivieren; dadurch wird die Installation nicht eingeschränkt. Benutzerdefinierte IMG-Installationen werden nur als Kompatibilitätsdiagnosen und niemals in diesem Kartenstrom gemeldet.

Speicherung und öffentliche Statistik

Kompatibilitätsberichte und datensparsame Kartenereignisse werden höchstens 24 Monate in der PostgreSQL-Datenbank von Terento auf der Hosting-Infrastruktur gespeichert und anschließend gelöscht. Der Zugriff ist auf den privaten Verwaltungsdienst beschränkt.

Terento veröffentlicht ausschließlich geprüfte, aggregierte Kompatibilitätsstatistiken. Rohberichte und Kartenereignisse werden nicht veröffentlicht.

Cloudflare und Hosting

Cloudflare stellt Dienste zur Auslieferung und Absicherung von Website und API bereit. Website, API und Datenbank laufen auf der Infrastruktur von Hostinger. Terento und diese Anbieter können IP-Adressen, Anfrage-Metadaten und sicherheitsbezogene Informationen verarbeiten, um diese Dienste zu betreiben und zu schützen. Es gelten die Datenschutzerklärung von Cloudflare und die Datenschutzerklärung von Hostinger.

Umami-Statistik

Die Website lädt das Umami-Analyseskript von stats.enduristas.lt für alle Besucher, um Besuche und Download-Ereignisse zu messen. Umami verwendet keine Tracking-Cookies und erstellt keine persönlichen Profile. Besuchsstatistiken werden auf Grundlage des berechtigten Interesses von Terento nach Art. 6 Abs. 1 lit. f DSGVO verarbeitet: Reichweite und Kampagnenleistung verstehen, die öffentliche Website verbessern und ein freies Open-Source-Projekt unterstützen.

Das Skript kann Seitenpfad, Referrer, Browser, Betriebssystem, Gerätetyp und Kontext auf Länderebene erfassen, um aggregierte Statistiken zu erstellen. Bei Kampagnenlinks können Download-Ereignisse nicht-personenbezogene UTM-Werte enthalten, um Quellen und Varianten zu unterscheiden. Dies dient der Kampagnenmessung, nicht Werbung oder persönlichem Profiling. Siehe die Umami-FAQ.

Spracheinstellung

Wenn du eine Sprache auswählst, speichert die Website die Einstellung als terento-language im lokalen Speicher deines Browsers. Das ist eine von dir angeforderte Einstellung und kein Werbetracking.

Cookies — was gilt

Diese Website verwendet keine Werbe- oder Profiling-Cookies. Umami-Besuchsstatistiken verwenden keine Tracking-Cookies und sind für alle Besucher aktiviert. Die Spracheinstellung wird nur bei deiner Auswahl in localStorage gespeichert. Cloudflare-Sicherheits-Cookies dienen, falls sie verwendet werden, der Infrastruktur und Sicherheit, nicht dem Marketing.

Es gibt kein Einwilligungs-Popup und keine Einstellung für die Analytik. Du kannst dieser Verarbeitung unter privacy@terento.app widersprechen.

Deine Rechte

Nach der DSGVO können Rechte auf Auskunft, Berichtigung, Löschung, Einschränkung, Widerspruch, Datenübertragbarkeit, Widerruf der Einwilligung und Beschwerde bei einer Aufsichtsbehörde bestehen. In Litauen ist dies die staatliche Datenschutzaufsicht (VDAI).

Nutze Terento → Diagnostics, um die zukünftige Diagnoseteilung zu beenden. Die App bietet keine Löschfunktion für hochgeladene Diagnosen. Für Datenschutzanfragen kontaktiere privacy@terento.app.

Die sichere Bereitstellung von Website und API, die Reichweitenanalyse, die Kampagnenmessung und die Verbesserung von Terento durch datensparsame Diagnosen beruhen auf berechtigten Interessen nach Art. 6 Abs. 1 lit. f DSGVO.

Site, application et données

Ce que Terento traite.

Données locales de l’application

Le site et l’application ne proposent ni compte ni connexion et n’exigent pas d’adresse e-mail. L’état de l’appareil, les cartes, les manifestes Terento et les enregistrements locaux d’installation restent sur votre Mac. L’application n’envoie par défaut que les champs de diagnostic limités au nécessaire décrits ci-dessous, jamais ces enregistrements locaux.

Vérifications automatiques des mises à jour

L’application peut contacter terento.app au démarrage pour vérifier si une version plus récente est disponible. Cette requête automatique n’est pas utilisée pour l’analyse ou le suivi des utilisateurs ; elle récupère uniquement les métadonnées de version. Terento ne télécharge, ne monte et n’installe pas la DMG en arrière-plan.

Diagnostics de compatibilité limités au nécessaire

La bêta macOS envoie par défaut à api.terento.app des diagnostics de compatibilité limités au nécessaire afin d’améliorer la fiabilité des installations et la couverture par modèle de montre et firmware. Il n’y a pas de choix de partage dans le parcours d’installation. Vous pouvez désactiver ce flux à tout moment dans Terento → Diagnostics ; cela ne limite ni l’application ni l’installation des cartes.

Un rapport peut contenir des identifiants aléatoires d’événement et d’opération d’installation, un horodatage, le modèle et la famille de la montre, le libellé MTP brut nettoyé, le firmware, les identifiants USB du fabricant et du produit, le transport MTP et une catégorie indiquant seulement si l’identité locale provient d’un numéro de série MTP, d’un Garmin Unit ID ou d’aucune source disponible. Il peut aussi contenir le fournisseur, les régions et versions de cartes sélectionnées, la version exacte de Terento et son build, la version de macOS, le résultat par carte, l’étape de l’échec, des codes Terento et natifs autorisés, le démarrage de l’écriture ou du nettoyage et une plage approximative de progression. Les erreurs antérieures à l’écriture sont séparées du taux de compatibilité de la montre. La valeur du Garmin Unit ID ou du numéro de série, l’identifiant local de montre, les données de compte, l’adresse e-mail, les chemins locaux, les identifiants d’objet MTP, les manifestes Terento, les fichiers ou hash de carte, le texte d’erreur brut et les journaux de diagnostic ne sont pas inclus.

Ces diagnostics servent à améliorer la qualité de l’application Terento, la fiabilité des installations et la couverture des appareils pris en charge. Vous pouvez arrêter le partage futur dans Terento → Diagnostics. L’application ne propose pas d’action de suppression pour les diagnostics envoyés ; pour exercer vos droits relatifs à la vie privée, écrivez à privacy@terento.app.

Diagnostics d’utilisation des cartes limités au nécessaire

L’application envoie par défaut un flux distinct de diagnostics limités au nécessaire concernant l’utilisation des cartes afin de mesurer les résultats des téléchargements et installations. Un événement contient uniquement des identifiants aléatoires d’événement et d’opération, l’horodatage, le fournisseur, la carte, la région, le type d’événement, le résultat et le build de l’application. Il ne contient ni identifiant de montre, ni numéro de série ou Garmin Unit ID, ni compte, chemin local, manifeste, fichier de carte ou journal de diagnostic. Vous pouvez désactiver ce flux dans Terento → Diagnostics ; cela ne limite pas l’installation. Les installations d’IMG personnalisées sont signalées uniquement par les diagnostics de compatibilité, jamais par ce flux d’utilisation des cartes.

Conservation et statistiques publiques

Les rapports de compatibilité et événements cartographiques limités au nécessaire sont conservés au maximum 24 mois dans la base PostgreSQL de Terento, puis supprimés. L’accès est limité au service d’administration privé.

Terento publie uniquement des statistiques agrégées et vérifiées. Les rapports et événements cartographiques bruts ne sont pas publiés.

Cloudflare et hébergement

Cloudflare fournit les services de diffusion et de protection du site et de l’API. Le site, l’API et la base de données fonctionnent sur l’infrastructure de Hostinger. Terento et ces prestataires peuvent traiter les adresses IP, les métadonnées des requêtes et des informations de sécurité afin d’exploiter et de protéger ces services. La politique de confidentialité de Cloudflare et la politique de confidentialité de Hostinger s’appliquent.

Statistiques Umami

Le site charge le script d’analyse Umami depuis stats.enduristas.lt pour tous les visiteurs afin de mesurer les visites et les téléchargements. Umami n’utilise pas de cookies de suivi et ne crée pas de profils personnels. Les statistiques de visite sont traitées sur la base de l’intérêt légitime de Terento au sens de l’article 6, paragraphe 1, point f) du RGPD : comprendre la portée du site et les performances des campagnes, améliorer le site public et soutenir un projet open source gratuit.

Le script peut enregistrer le chemin de la page, le référent, le navigateur, le système d’exploitation, le type d’appareil et un contexte au niveau du pays pour produire des statistiques agrégées. Les téléchargements liés à une campagne peuvent contenir des valeurs UTM non personnelles pour distinguer les sources et variantes. Il s’agit de mesure de campagne, non de publicité ni de profilage personnel. Voir la FAQ Umami.

Préférence de langue

Lorsque vous choisissez la langue du site, celui-ci enregistre cette préférence sous terento-language dans le stockage local de votre navigateur. Il s’agit d’une préférence demandée par vous, et non d’un suivi publicitaire.

Cookies — règles applicables

Ce site n’utilise pas de cookies publicitaires ou de profilage. Les statistiques de visite Umami n’utilisent pas de cookies de suivi et sont activées pour tous les visiteurs. Les cookies de sécurité Cloudflare, s’ils sont utilisés, servent à l’infrastructure et à la sécurité, et non au marketing.

Strona, aplikacja i dane

Jakie dane przetwarza Terento.

Lokalne dane aplikacji

Strona i aplikacja nie oferują konta ani logowania i nie wymagają adresu e-mail. Stan urządzenia, mapy, manifesty Terento i lokalne zapisy instalacji pozostają na Twoim Macu. Aplikacja domyślnie wysyła tylko opisane poniżej, ograniczone do niezbędnego minimum pola diagnostyczne i nigdy nie wysyła tych lokalnych zapisów.

Automatyczne sprawdzanie aktualizacji

Aplikacja może przy uruchomieniu skontaktować się z terento.app, aby sprawdzić, czy jest dostępna nowsza wersja. To automatyczne żądanie nie służy do analityki ani śledzenia użytkowników; pobiera tylko metadane wydania. Terento nie pobiera, nie montuje ani nie instaluje DMG w tle.

Diagnostyka zgodności ograniczona do niezbędnego minimum

Wersja beta dla macOS domyślnie wysyła do api.terento.app ograniczoną do niezbędnego minimum, diagnostykę zgodności ograniczoną do niezbędnego minimum, aby poprawiać niezawodność instalacji i pokrycie modeli zegarków oraz wersji firmware. W procesie instalacji nie ma wyboru udostępniania. Ten strumień możesz w każdej chwili wyłączyć w Terento → Diagnostics; nie ograniczy to aplikacji ani instalowania map.

Raport może zawierać losowe identyfikatory zdarzenia i operacji instalacji, czas, model i rodzinę zegarka, oczyszczoną surową etykietę modelu MTP, firmware, identyfikatory producenta i produktu USB, transport MTP oraz kategorię wskazującą wyłącznie, czy lokalna tożsamość pochodzi z numeru seryjnego MTP, Garmin Unit ID, czy była niedostępna. Może też zawierać dostawcę, wybrane regiony i wydania map, dokładną wersję beta/build Terento, wersję macOS, wynik każdej mapy, etap awarii, dozwolone kody Terento i natywne, informację o rozpoczęciu zapisu lub czyszczenia oraz przybliżony zakres postępu transferu. Błędy sprzed zapisu są oddzielone od wskaźnika zgodności zegarka. Wartość Garmin Unit ID lub numeru seryjnego, lokalny identyfikator zegarka, dane konta, adres e-mail, lokalne ścieżki, identyfikatory obiektów MTP, manifesty Terento, pliki ani hashe map, surowy tekst błędu i dzienniki diagnostyczne nie są zawarte.

Diagnostyka służy poprawie jakości aplikacji Terento, niezawodności instalacji i obsługi kolejnych urządzeń. Przyszłe udostępnianie możesz wyłączyć w Terento → Diagnostics. Aplikacja nie udostępnia opcji usuwania przesłanej diagnostyki; w sprawach dotyczących praw do prywatności napisz na privacy@terento.app.

Diagnostyka użycia map ograniczona do niezbędnego minimum

Aplikacja domyślnie wysyła osobny strumień ograniczonej do niezbędnego minimum, diagnostyki użycia map ograniczonej do niezbędnego minimum, aby mierzyć wyniki pobierania i instalacji. Zdarzenie zawiera tylko losowe identyfikatory zdarzenia i operacji, czas, dostawcę, mapę, region, typ zdarzenia, wynik i build aplikacji. Nie zawiera identyfikatora zegarka, numeru seryjnego ani Garmin Unit ID, konta, lokalnych ścieżek, manifestu, pliku mapy ani dziennika diagnostycznego. Ten strumień możesz wyłączyć w Terento → Diagnostics; nie ograniczy to instalacji. Instalacje niestandardowych plików IMG są zgłaszane wyłącznie jako diagnostyka zgodności, nigdy w tym strumieniu użycia map.

Przechowywanie i statystyki publiczne

Raporty zgodności i zdarzenia map ograniczone do niezbędnego minimum są przechowywane w bazie PostgreSQL Terento nie dłużej niż 24 miesiące, po czym są usuwane. Dostęp jest ograniczony do prywatnej usługi administracyjnej.

Terento publikuje wyłącznie sprawdzone statystyki zagregowane. Surowe raporty i zdarzenia map nie są publikowane.

Cloudflare i hosting

Cloudflare świadczy usługi dostarczania i ochrony strony oraz API. Strona, API i baza danych działają na infrastrukturze Hostinger. Terento i ci dostawcy mogą przetwarzać adresy IP, metadane żądań i informacje bezpieczeństwa w celu obsługi i ochrony tych usług. Obowiązują polityka prywatności Cloudflare i polityka prywatności Hostinger.

Statystyki Umami

Web, aplikace a data

Co Terento zpracovává.

Místní data aplikace

Web a aplikace neposkytují účet ani přihlášení a nevyžadují e-mailovou adresu. Stav zařízení, mapy, manifesty Terento a místní záznamy instalací zůstávají na vašem Macu. Aplikace ve výchozím nastavení odesílá pouze níže popsaná diagnostická pole v nezbytném rozsahu a tyto místní záznamy nikdy neodesílá.

Automatické kontroly aktualizací

Aplikace může při spuštění kontaktovat terento.app a ověřit, zda je k dispozici novější verze. Tento automatický požadavek neslouží k analytice ani sledování uživatelů; načítá pouze metadata vydání. Terento DMG na pozadí nestahuje, nepřipojuje ani neinstaluje.

Diagnostika kompatibility v nezbytném rozsahu

Beta verze pro macOS ve výchozím nastavení odesílá na api.terento.app diagnostiku kompatibility v nezbytném rozsahu, aby zlepšila spolehlivost instalací a pokrytí podle modelu hodinek a firmwaru. V instalačním procesu není žádná volba sdílení. Tento proud můžete kdykoli vypnout v Terento → Diagnostics; vypnutí neomezuje aplikaci ani instalaci map.

Hlášení může obsahovat náhodná ID události a instalační operace, čas, model a řadu hodinek, očištěný surový štítek modelu MTP, firmware, identifikátory výrobce a produktu USB, přenos MTP a kategorii, která pouze uvádí, zda místní identita pochází ze sériového čísla MTP, Garmin Unit ID, nebo nebyla dostupná. Dále může obsahovat poskytovatele, vybrané oblasti a vydání map, přesnou beta/build verzi Terento, verzi macOS, výsledek každé mapy, fázi selhání, povolené kódy Terento a nativní kódy, informaci o zahájení zápisu nebo úklidu a přibližný rozsah průběhu přenosu. Chyby před zápisem jsou odděleny od míry kompatibility hodinek. Hodnota Garmin Unit ID nebo sériového čísla, místní identifikátor hodinek, údaje účtu, e-mail, místní cesty, ID objektů MTP, manifesty Terento, mapové soubory ani jejich hashe, nezpracovaný text chyby a diagnostické protokoly nejsou zahrnuty.

Tato diagnostika slouží ke zlepšení kvality aplikace Terento, spolehlivosti instalací a podpory dalších zařízení. Budoucí sdílení můžete zastavit v Terento → Diagnostics. Aplikace nenabízí možnost odstranění odeslané diagnostiky; s žádostmi týkajícími se práv na ochranu soukromí se obraťte na privacy@terento.app.

Diagnostika používání map v nezbytném rozsahu

Aplikace ve výchozím nastavení odesílá samostatný proud diagnostiky používání map v nezbytném rozsahu, aby měřila výsledky stahování a instalace map. Událost obsahuje pouze náhodná ID události a operace, čas, poskytovatele, mapu, oblast, typ události, výsledek a build aplikace. Neobsahuje identifikátor hodinek, sériové číslo ani Garmin Unit ID, účet, místní cesty, manifest, mapový soubor ani diagnostický protokol. Tento proud můžete vypnout v Terento → Diagnostics; instalaci to neomezuje. Instalace vlastních souborů IMG se hlásí pouze jako diagnostika kompatibility, nikdy jako diagnostika používání map.

Uchovávání a veřejné statistiky

Hlášení o kompatibilitě a mapové události v nezbytném rozsahu se uchovávají v databázi PostgreSQL Terento nejdéle 24 měsíců a poté se odstraní. Přístup je omezen na soukromou administrační službu.

Terento zveřejňuje pouze zkontrolované agregované statistiky. Nezpracovaná hlášení ani mapové události se nezveřejňují.

Cloudflare a hosting

Cloudflare zajišťuje doručování a ochranu webu a API. Web, API a databáze běží na infrastruktuře Hostinger. Terento a tito poskytovatelé mohou zpracovávat IP adresy, metadata požadavků a bezpečnostní informace za účelem provozu a ochrany těchto služeb. Platí zásady Cloudflare a zásady Hostinger.

Statistiky návštěvnosti se zpracovávají na základě oprávněného zájmu Terento podle čl. 6 odst. 1 písm. f) GDPR: porozumět dosahu webu a výkonu kampaní, zlepšovat veřejný web a podporovat bezplatný open-source projekt.

Skript může zaznamenávat cestu stránky, odkazující stránku, prohlížeč, operační systém, typ zařízení a kontext na úrovni země za účelem vytváření agregovaných statistik. Události stahování z kampaní mohou obsahovat neosobní hodnoty UTM pro rozlišení zdrojů a variant. Jde o měření kampaní, nikoli o reklamu nebo osobní profilování. Viz FAQ Umami.

Sito, app e dati

Cosa tratta Terento.

Dati locali dell’app

Il sito e l’app non forniscono account o accesso e non richiedono un indirizzo e-mail. Stato del dispositivo, mappe, manifest Terento e registrazioni locali delle installazioni restano sul tuo Mac. L’app invia per impostazione predefinita solo i campi diagnostici ridotti al minimo necessari descritti sotto e non invia mai queste registrazioni locali.

Controlli automatici degli aggiornamenti

L’app può contattare terento.app all’avvio per verificare se è disponibile una versione più recente. Questa richiesta automatica non viene usata per analisi o tracciamento degli utenti; recupera solo metadati della release. Terento non scarica, monta o installa la DMG in background.

Diagnostica della compatibilità ridotta al necessario

La beta per macOS invia per impostazione predefinita a api.terento.app dati diagnostici ridotti al minimo necessario sulla compatibilità, per migliorare l’affidabilità delle installazioni e la copertura per modello di orologio e firmware. Nel flusso di installazione non c’è una scelta di condivisione. Puoi disattivare questo flusso in qualsiasi momento in Terento → Diagnostics; la disattivazione non limita l’app né l’installazione delle mappe.

Un rapporto può contenere ID casuali dell’evento e dell’operazione, data e ora, modello e famiglia dell’orologio, etichetta grezza del modello MTP ripulita, firmware, identificativi USB del produttore e del prodotto, trasporto MTP e una categoria che indica soltanto se l’identità locale proviene da un numero di serie MTP, da un Garmin Unit ID o non era disponibile. Può inoltre contenere fornitore, regioni e versioni delle mappe, versione beta/build esatta di Terento, risultato per mappa, fase e codici controllati dell’errore, stato di scrittura e pulizia e una fascia approssimativa di avanzamento. Gli errori precedenti alla scrittura non incidono sul tasso di compatibilità dell’orologio. Il valore del Garmin Unit ID o del numero di serie, l’identificatore locale dell’orologio, account, e-mail, percorsi locali, ID oggetto MTP, manifest, file o hash delle mappe, testo grezzo degli errori e registri diagnostici non sono inclusi.

Questa diagnostica serve a migliorare la qualità dell’app Terento, l’affidabilità delle installazioni e il supporto di ulteriori dispositivi. Puoi interrompere la condivisione futura in Terento → Diagnostics. L’app non offre un’azione per eliminare la diagnostica inviata; per richieste relative ai diritti sulla privacy scrivi a privacy@terento.app.

Diagnostica sull’uso delle mappe ridotta al necessario

L’app invia per impostazione predefinita un flusso separato di diagnostica ridotta al minimo necessario sull’uso delle mappe, per misurare gli esiti di download e installazione. Un evento contiene solo ID casuali di evento e operazione, data e ora, fornitore, mappa, regione, tipo di evento, esito e build dell’app. Non contiene identificatori dell’orologio, numero di serie o Garmin Unit ID, account, percorsi locali, manifest, file delle mappe o registri diagnostici. Puoi disattivare questo flusso in Terento → Diagnostics; l’installazione non ne risente. Le installazioni di file IMG personalizzati vengono segnalate solo tramite la diagnostica di compatibilità, mai tramite questo flusso sull’uso delle mappe.

Conservazione e statistiche pubbliche

I rapporti di compatibilità e gli eventi sulle mappe ridotti al necessario sono conservati nel database PostgreSQL di Terento per non più di 24 mesi e poi eliminati. L’accesso è limitato al servizio di amministrazione privato.

Terento pubblica solo statistiche aggregate e verificate. I rapporti e gli eventi grezzi non vengono pubblicati.

Cloudflare e hosting

Cloudflare fornisce i servizi di distribuzione e protezione del sito e dell’API. Sito, API e database funzionano sull’infrastruttura Hostinger. Terento e questi fornitori possono trattare indirizzi IP, metadati delle richieste e informazioni di sicurezza per gestire e proteggere tali servizi. Si applicano le informative di Cloudflare e Hostinger.

Statistiche Umami

Il sito carica lo script di analisi Umami da stats.enduristas.lt per tutti i visitatori, per misurare le visite e gli eventi di download. Umami non usa cookie di tracciamento e non crea profili personali. Le statistiche delle visite sono trattate sulla base del legittimo interesse di Terento ai sensi dell’art. 6, par. 1, lett. f) del GDPR: comprendere la portata del sito e i risultati delle campagne, migliorare il sito pubblico e sostenere un progetto open source gratuito.

Lo script può registrare il percorso della pagina, il referrer, il browser, il sistema operativo, il tipo di dispositivo e il contesto a livello di paese per produrre statistiche aggregate. Gli eventi di download provenienti da link di campagna possono contenere valori UTM non personali per distinguere fonti e varianti. È una misurazione delle campagne, non pubblicità o profilazione personale. Vedi le FAQ di Umami.

Preferenza della lingua

Quando scegli la lingua del sito, il sito salva la preferenza come terento-language nell’archiviazione locale del browser. È una preferenza richiesta dall’utente, non un tracciamento pubblicitario.

Cookie — cosa si applica

Questo sito non usa cookie pubblicitari o di profilazione. Le statistiche delle visite Umami non usano cookie di tracciamento e sono attivate per tutti i visitatori. La preferenza della lingua viene salvata in localStorage solo quando scegli una lingua. I cookie di sicurezza Cloudflare, se usati, servono all’infrastruttura e alla sicurezza, non al marketing.

Non viene mostrato alcun popup di consenso né un’impostazione per l’analisi. Puoi opporti a questo trattamento scrivendo a privacy@terento.app.
