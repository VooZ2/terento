Poradnik dla Garmin Edge

# Zainstaluj mapy na Garmin Edge z Maca

Nowsze liczniki rowerowe Garmin Edge nie pojawiają się na Macu jako dysk, więc nie da się po prostu skopiować na nie pliku mapy. Terento w trzech krokach instaluje darmowe mapy OpenStreetMap albo Twój własny zgodny plik mapy na Edge z obsługą map.

Dlaczego to działa inaczej

## Dlaczego Garmin Edge nie pojawia się na Macu

Nowsze modele Edge, takie jak Edge 540, 840 i 1050, przesyłają pliki przez USB tak jak telefony z Androidem, za pomocą MTP (Media Transfer Protocol). macOS nie obsługuje go fabrycznie, dlatego Edge nie pojawia się w Finderze jako dysk, a poradniki, które każą skopiować plik mapy do folderu Garmin, nie działają w przypadku tych modeli. Terento komunikuje się z Edge bezpośrednio, więc nie potrzebujesz Android File Transfer ani OpenMTP.

Szybka kontrola

## Zanim zaczniesz

- Mac z Apple Silicon i macOS 13 lub nowszym
- Nowszy Garmin Edge z obsługą map
- Kabel USB obsługujący przesyłanie danych

Terento jest przeznaczone dla nowszych modeli Edge z obsługą map, które łączą się w ten sposób: Edge 540, Edge 540 Solar, Edge 840, Edge 840 Solar, Edge 1040, Edge 1040 Solar, Edge 1050, Edge 550, Edge 850, Edge 1060, Edge MTB, Edge Explore 2, Edge Explore 3 i Edge Explore 3 Plus. Po podłączeniu Terento sprawdzi Edge i powie, czy może zainstalować mapy. Strona zgodności pokazuje dokładne modele z udanymi instalacjami; brak modelu nie oznacza, że nie jest obsługiwany.

[Zobacz aktualne dowody zgodności](https://terento.app/pl/compatibility/)

Nie masz Maca z Apple Silicon? [Instalator webowy](https://terento.app/pl/install/) instaluje mapy z katalogu z Chrome i innych przeglądarek Chromium z WebUSB.

Trzy kroki

## Zainstaluj mapę na Edge

1. Podłącz Edge

[Pobierz Terento](https://terento.app/pl/download/) i otwórz je. Zamknij Garmin Express, podłącz Edge bezpośrednio do Maca kablem USB do przesyłania danych i poczekaj do 2 minut, aż Terento go wykryje.

2. Wybierz mapę

Wybierz dostawcę i region z katalogu albo dodaj z Maca własny zgodny plik mapy .img. [Porównaj style map](https://terento.app/pl/map-styles/), aby zobaczyć, jak każda mapa pokazuje drogi i szlaki.

3. Zainstaluj

Rozpocznij instalację i nie odłączaj Edge, dopóki Terento nie poinformuje, że instalacja się zakończyła. Potem odłącz Edge.

Po instalacji

## Wyświetl mapę na Edge

### Włącz mapę

Odłącz Edge, otwórz jego ustawienia map i sprawdź, czy nowa mapa jest włączona. Jeśli nie ma jej na liście, uruchom Edge ponownie. Jeśli kilka map obejmuje ten sam obszar, wyłącz te, których nie chcesz widzieć.

### Garmin Edge nie pojawia się w Terento

Użyj kabla USB do przesyłania danych, podłącz Edge bezpośrednio zamiast przez hub, zamknij Garmin Express i aplikacje do przesyłania plików, a potem poczekaj do 2 minut. W [poradniku rozwiązywania problemów](https://terento.app/pl/guides/troubleshooting/) znajdziesz więcej kroków; większość działa tak samo dla zegarka i dla Edge.

### Starsze modele Edge

Starsze modele, takie jak Edge 1030 Plus i wcześniejsze, zwykle pojawiają się na Macu jako dysk USB. Na nich możesz samodzielnie skopiować zgodny plik mapy .img do folderu Garmin na dysku, bez Terento. Terento nie jest przeznaczone dla tych modeli.
