Průvodce pro Garmin Edge

Instalace map do Garmin Edge z Macu

Novější cyklopočítače Garmin Edge se na Macu nezobrazí jako disk, takže do nich nelze jednoduše zkopírovat mapový soubor. Terento ve třech krocích nainstaluje bezplatné mapy OpenStreetMap nebo váš vlastní kompatibilní mapový soubor do Edge s podporou map.

Proč je to jinak

Proč se Garmin Edge na Macu nezobrazí

Novější modely Edge, například Edge 540, 840 a 1050, přenášejí soubory přes USB stejně jako telefony s Androidem, pomocí MTP (Media Transfer Protocol). macOS ho sám nepodporuje, proto se Edge ve Finderu nezobrazí jako disk a návody, podle kterých máte mapový soubor zkopírovat do složky Garmin, u těchto modelů nefungují. Terento s Edge komunikuje přímo, takže nepotřebujete Android File Transfer ani OpenMTP.

Rychlá kontrola

Než začnete

  • Mac s Apple Silicon a macOS 13 nebo novějším
  • Novější Garmin Edge s podporou map
  • USB kabel s podporou přenosu dat

Terento je určené pro novější modely Edge s podporou map, které se připojují tímto způsobem: Edge 540, Edge 540 Solar, Edge 840, Edge 840 Solar, Edge 1040, Edge 1040 Solar, Edge 1050, Edge 550, Edge 850, Edge 1060, Edge MTB, Edge Explore 2, Edge Explore 3 a Edge Explore 3 Plus. Po připojení Terento Edge zkontroluje a řekne vám, zda do něj může mapy nainstalovat. Stránka Kompatibilita uvádí přesné modely s úspěšnými instalacemi; chybějící model nemusí znamenat, že není podporován.

Nemáte Mac s Apple Silicon? Webový instalátor instaluje mapy z katalogu z Chrome a dalších prohlížečů Chromium s WebUSB.

Tři kroky

Instalace mapy do Edge

  1. 01

    Připojte Edge

    Stáhněte Terento a otevřete ho. Ukončete Garmin Express, připojte Edge přímo k Macu USB kabelem pro přenos dat a počkejte až 2 minuty, než ho Terento najde.

  2. 02

    Vyberte mapu

    Vyberte poskytovatele a oblast z katalogu, nebo přidejte z Macu vlastní kompatibilní mapový soubor .img. Porovnejte styly map a podívejte se, jak každá mapa zobrazuje silnice a stezky.

  3. 03

    Instalujte

    Spusťte instalaci a nechte Edge připojený, dokud Terento neoznámí, že je instalace hotová. Potom Edge odpojte.

Po instalaci

Zobrazení mapy v Edge

Zapněte mapu

Odpojte Edge, otevřete jeho nastavení map a zkontrolujte, že je nová mapa zapnutá. Pokud v seznamu není, Edge restartujte. Pokud stejnou oblast pokrývá více map, vypněte ty, které vidět nechcete.

Terento nevidí Garmin Edge

Použijte USB kabel pro přenos dat, připojte Edge přímo, ne přes rozbočovač, ukončete Garmin Express a aplikace pro přenos souborů a počkejte až 2 minuty. Další kroky najdete v průvodci řešením potíží; většina z nich platí stejně pro hodinky i Edge.

Starší modely Edge

Starší modely, například Edge 1030 Plus a dřívější, se na Macu obvykle zobrazí jako USB disk. U nich můžete kompatibilní mapový soubor .img sami zkopírovat do složky Garmin na disku, bez Terento. Terento není pro tyto modely určené.
