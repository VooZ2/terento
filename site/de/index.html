Open-Source-Projekt · Beta

Dein Gerät, bereit für dein nächstes Ziel.

Terento ist eine kostenlose Open-Source-Beta für macOS zur Installation von Freizeitkarte-Karten auf ausgewählten Garmin-Smartwatches. Sie erfordert einen Apple-Silicon-Mac; Intel-Macs werden nicht unterstützt.

Beta verfügbar · Mit mehreren Uhren getestet; Kartenunterstützung hängt vom Gerät ab.

Beta herunterladen ↘

So funktioniert es

Verbinden → Installieren → Loslegen

Die Installation von Karten sollte keine Dateimanager, Geräteordner oder veralteten Übertragungstools erfordern.

Die Terento-Beta bringt diesen Ablauf in eine native macOS-App.

Verbinden

02

Gute Fragen

FAQ

Ist die Beta verfügbar?

Ja. Eine notarisierte Beta ist für Apple-Silicon-Macs mit macOS 13 oder neuer verfügbar. Sie ist Pre-MVP und die Kompatibilität wird weiter getestet. Beta herunterladen.

Was macht Terento?

Terento ist eine native macOS-App zur Installation von Freizeitkarte-Karten auf ausgewählten Garmin-Smartwatches.

Was wurde getestet?

Mehrere Garmin-Uhren wurden getestet. Einige unterstützen keine Karten, daher hängt die Kompatibilität vom Gerät ab. Die Beta konzentriert sich derzeit auf Freizeitkarte.

Ist Terento Open Source?

Ja. Terento ist kostenlos und steht unter GPL-3.0-or-later.
