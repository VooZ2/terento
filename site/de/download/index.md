# Terento für Mac herunterladen

Eine kostenlose Open-Source-App, die freie Karten auf Garmin-Uhren und Edge-Fahrradcomputer mit Kartenunterstützung installiert.

[Für Mac herunterladen](https://github.com/VooZ2/terento/releases/download/v1.3.0-build50/Terento-1.3.0-macOS-arm64.dmg) [Laden im Mac App Store](https://apps.apple.com/app/apple-store/id6828556832?pt=129348028&ct=site-download&mt=8)

[Nutze den Web-Installer](https://terento.app/de/install/)

Terento zeigt eine verbundene Garmin-Uhr unter macOS

## Das brauchst du

Neueste Version **v1.3.0**, 22. November 2026. [Was ist neu](https://github.com/VooZ2/terento/releases/tag/v1.3.0-build50) [Auf GitHub einen Stern geben](https://github.com/VooZ2/terento)

- Einen Mac mit Apple Silicon
- macOS 13 oder neuer
- Ein USB-Datenkabel, kein reines Ladekabel
- Eine Garmin-Uhr oder einen Garmin Edge Fahrradcomputer
[Kompatibilität prüfen](https://terento.app/de/compatibility/)

## Nach dem Download

1. Terento öffnen

Öffne die heruntergeladene Datei und ziehe Terento in den Ordner „Programme“.

2. Garmin verbinden

Nutze ein USB-Datenkabel und entsperre Uhr oder Edge.

3. Karte wählen

Wähle eine Karte und eine Region und installiere sie. Schalte die Karte dann in den Karteneinstellungen deines Garmin ein (fehlt sie in der Liste, starte das Gerät neu).

Schritt für Schritt: [Anleitung für Garmin-Uhren](https://terento.app/de/guides/install-garmin-maps-mac/) und [Anleitung für Garmin Edge](https://terento.app/de/guides/install-garmin-maps-edge-mac/).
