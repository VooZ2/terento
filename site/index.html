Good questions

FAQ

Which Garmin watches work with Terento?

See the Compatibility page for Garmin models and variants confirmed by real installations.

Can I install third-party maps on a Garmin watch from a Mac without BaseCamp?

Yes. Terento takes you from choosing a map to installing it on your watch. You can also add a compatible map file from your Mac. Apple Silicon is required. Read the installation guide.

Is Terento safe for existing Garmin maps?

Yes. Garmin and system maps remain protected. Terento changes only supported third-party maps after you confirm the action.

Which third-party map providers does Terento support?

Terento uses the supported providers shown above. Maps are downloaded directly from the original provider.

What should I do if installation fails?

Open a GitHub issue or email the diagnostic log. It contains what we need to investigate the problem.
