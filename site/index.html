Good questions

FAQ

Which Garmin watches work with Terento?

Terento is designed for Garmin smartwatches with map support. Public compatibility for third-party map installation is confirmed by exact model and variant using real results shared by users. See the Compatibility page for the current evidence.

Can I install third-party maps on a Garmin watch from a Mac without BaseCamp?

Yes. Terento provides a guided native macOS workflow for installing supported third-party maps without BaseCamp or a general-purpose MTP file manager. The current beta uses Freizeitkarte and requires an Apple Silicon Mac. Read the full Mac installation guide.

Is Terento safe for existing Garmin maps?

Yes. Existing Garmin maps are left unchanged. Terento manages only maps it has installed and recorded locally.

Where do the maps come from?

The current beta uses Freizeitkarte as its map source. Terento downloads maps from the original provider to your Mac, then transfers them to your watch.

Does Terento upload device data?

Compatibility sharing is optional. When enabled, only privacy-minimised installation evidence is shared; Garmin unit IDs, serial numbers and local paths are not.

Why is Apple Silicon required?

The current native macOS beta is built for Apple Silicon Macs running macOS 13 or later.

Can I back up or remove installed maps?

You can back up or remove Terento-managed maps from the app. Other maps remain read-only.
