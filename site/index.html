Open-source project · Beta

Your device, ready for where you're going.

Terento is a free, open-source macOS beta for installing Freizeitkarte maps on selected Garmin smartwatches. It requires an Apple Silicon Mac; Intel Macs are not supported.

Beta available · Tested with several watches; map support varies by device.

Download the beta ↘

How it works

Connect → Install → Go

Installing maps shouldn't require file managers, device folders or outdated transfer tools.

The Terento beta brings that workflow into a native macOS app.

01

Connect

Connect your Garmin smartwatch to your Mac.

02

Install

Choose a Freizeitkarte map and install it from the beta.

03

Go

Your watch is ready for where you're going.

Good questions

FAQ

Is the beta available?

Yes. A notarized beta is available for Apple Silicon Macs running macOS 13 or later. It is pre-MVP, and compatibility is still being tested. Download the beta.

What is Terento trying to do?

Terento is a native macOS app for installing Freizeitkarte maps on selected Garmin smartwatches.

What are you testing first?

Several Garmin watches have been tested. Some do not support maps, so compatibility depends on the device. The beta currently focuses on Freizeitkarte.

Is Terento open source?

Yes. Terento is free and open source under GPL-3.0-or-later.
