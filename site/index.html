Your device, ready for where you're going.

Terento is an open-source project exploring a simpler way to install community maps on modern Garmin smartwatches from a Mac.

Currently validating the first Garmin + macOS workflow.

Learn what we're testing ↘

What we're building

Connect → Install → Go

Community maps shouldn't require file managers, device folders and outdated transfer tools.

Terento is being built to make that process disappear.

01

Connect

Connect your Garmin smartwatch to your Mac.

Install

Terento is being built to find and install the community map you need.

Good questions

FAQ

Is Terento available yet?

Not yet. The project is currently in technical validation.

What is Terento trying to do?

Make installing community maps on modern Garmin smartwatches from a Mac much simpler.

What are you testing first?

Apple Silicon Macs, modern Garmin smartwatches using MTP, and Freizeitkarte.

Will Terento be open source?

Yes. Terento is being developed as a free, open-source project.
