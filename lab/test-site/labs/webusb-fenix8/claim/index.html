Technical scope

The flow reads the current USB device object, verifies the observed descriptor target, optionally selects configuration 1, claims interface 0, and uses only GetDeviceInfo, OpenSession, GetStorageIDs, GetStorageInfo and CloseSession.

Every protocol container is length-checked and transaction-checked. The page does not request object handles, object metadata, object content, filenames or paths.
