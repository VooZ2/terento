Technical scope

Allowed calls: OpenSession, GetStorageIDs, GetStorageInfo, GetObjectHandles, GetObjectInfo, GetObject and CloseSession. The selected objects are rediscovered by filename under the observed GARMIN association before every run.

Forbidden calls are not implemented: SendObjectInfo, SendObject, DeleteObject, MoveObject and SetObjectProperty. Cleanup always attempts CloseSession, release of interface 0 and device close.
